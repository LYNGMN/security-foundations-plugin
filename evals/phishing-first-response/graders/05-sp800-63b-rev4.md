PASS if the password policy matches NIST SP 800-63B Rev. 4: minimum 8 characters when used with MFA, minimum 15 characters when the password is the only factor, accepts at least 64 characters, and no arbitrary periodic rotation (change only on evidence of compromise).
FAIL if any of these four is missing or wrong, or if it recommends composition rules or 90-day rotation.
